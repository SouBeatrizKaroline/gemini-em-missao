## 🌟 Sobre este repositório

Este é o meu diário de bordo durante minha jornada como **Embaixadora Estudantil do Google**. 🚀

O objetivo é registrar cronologicamente minha evolução no programa: as atividades propostas, desafios, respostas enviadas, conteúdos publicados, vídeos, imagens, experimentos com Gemini e aprendizados de cada etapa.

Cada registro procura responder:

> 📋 **O que foi solicitado?**

> 🤖 **Como utilizei o Gemini?**  
> 🎨 **O que produzi?**  
> 🔗 **Onde publiquei?**  
> 📸 **Quais são as evidências?**  
> 💡 **O que aprendi?**
